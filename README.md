## 📝 How to Setup a Remote Repo on GitHub

1. Create a new repository on GitHub (Settings → New Repository)
2. Initialize git locally: `git init`
3. Configure git user info: 
   ```bash
   git config user.name "YourName"
   git config user.email "your@email.com"
   ```
4. Add remote origin: `git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git`
5. Create initial commit and push:
   ```bash
   git add .
   git commit -m "Initial commit"
   git push -u origin main
   ```
